# AI 产品经理成长路线 / AI 产品经理学习平台

一个开源公益的「AI 产品经理从 0 到 1 学习平台」。它不是单页路线图，而是一套可以持续阅读、练习、做项目、整理作品集的 Markdown 课程站点。

项目使用 React + TypeScript + Vite + Tailwind CSS 构建，课程、模板、术语和实战项目都存放在 `content/` 目录，方便社区用 Pull Request 持续维护。

## 项目适合谁

- 想从传统产品经理转向 AI 产品经理的人。
- 没有 AI 背景，希望系统理解 LLM、Prompt、RAG、Agent 的新手。
- 需要准备 AI 产品经理面试、作品集和项目材料的学习者。
- 希望参与开源课程建设的产品经理、工程师、设计师和教育内容贡献者。

## 你可以学到什么

- AI 产品经理岗位认知、能力模型和职业路径。
- 用户调研、需求分析、竞品分析、PRD、原型和项目推进。
- LLM、Prompt、Token、Embedding、向量数据库、RAG、Agent、评估等 AI 基础。
- AI 聊天助手、知识库问答、图片生成、智能客服、Agent 工作流等产品设计方法。
- API、流式响应、数据结构、日志监控、模型成本和技术协作方式。
- 从 0 到 1 完成实战项目，并沉淀为作品集。
- AI 产品商业化、增长、指标、成本优化、风险合规和面试表达。

## 当前内容结构

```text
content/
  course/       7 个阶段的系统课程
  projects/     6 个完整实战项目教程
  templates/    15 个可直接复制使用的产品模板
  glossary/     AI 产品经理高频术语库
docs/
  content-style-guide.md
```

课程页面支持 Markdown 渲染、目录跳转、阅读进度和 localStorage 学习进度。模板库、术语库和搜索页会自动读取 `content/` 下的 Markdown 内容。

## 课程阶段

1. 认识 AI 产品经理
2. 产品经理基础能力
3. AI 基础知识
4. AI 产品设计方法
5. 技术协作与落地
6. 实战项目训练
7. 高阶 AI 产品经理能力

## 实战项目

- AI 聊天助手产品设计
- 企业知识库问答系统
- AI 图片生成平台
- AI 智能客服系统
- AI Agent 自动化工作流平台
- AI 产品官网与商业化落地

每个项目教程都包含背景、用户、痛点、MVP、功能清单、页面结构、用户流程、AI 能力点、技术协作、数据指标、PRD 大纲、原型说明、Prompt 设计、风险边界和作品集产出。

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

预览构建结果：

```bash
npm run preview
```

## 如何贡献

1. 阅读 [CONTRIBUTING.md](./CONTRIBUTING.md)。
2. 参考 [docs/content-style-guide.md](./docs/content-style-guide.md)。
3. 在 `content/` 下新增或修改 Markdown。
4. 确保 frontmatter 与加载器兼容。
5. 提交前运行 `npm run build`。

优先欢迎贡献：课程案例补充、项目教程迭代、模板示例完善、术语补充、错别字修复、可读性优化和适合新手的图示设计。

## 图片占位规则

课程和项目教程会预留图片位置，但仓库不要求提交生成图片。请使用统一文本格式：

```md
> 图片占位
> 建议文件名：example.png
> 图片用途：说明这张图用于帮助学习者理解什么。
> 生图提示词：中文提示词，16:9，清爽科技教育风格，蓝紫渐变，无水印，无真实品牌 Logo。
```

所有课程、模板、术语和案例文字必须原创。可以分析公开产品体验，但必须用自己的语言总结，不复制第三方文章、课程、书籍、官网文案或商业文档。
