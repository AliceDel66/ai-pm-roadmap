# 内容目录说明

这里存放站点的 Markdown 内容。目录按课程、项目、模板和术语组织，方便社区通过 Pull Request 贡献。

## 目录结构

```text
content/
	course/       7 个学习阶段的课程
	projects/     6 个实战项目教程
	templates/    AI 产品经理常用模板
	glossary/     AI 产品经理术语库
```

## 推荐编辑顺序

1. 先在 `course/<stage-slug>/index.md` 维护阶段介绍。
2. 再为每节课新增或修改独立 Markdown 文件。
3. 实战项目教程放在 `projects/`。
4. 模板放在 `templates/`。
5. 术语解释放在 `glossary/`。

## 课程要求

课程建议包含学习目标、直觉解释、核心知识、AI 产品经理视角、案例拆解、方法论、常见误区、练习、作业、自测题、延伸学习和小结。

## 图片占位

课程和项目可以预留图片位置，格式如下：

```md
> 图片占位
> 建议文件名：example.png
> 图片用途：说明这张图用于帮助学习者理解什么。
> 生图提示词：中文提示词，16:9，清爽科技教育风格，蓝紫渐变，无水印，无真实品牌 Logo。
```

## 原创要求

所有课程内容必须原创，避免复制第三方文章、课程、书籍、官网或商业文档。案例可以参考公开产品体验，但必须用自己的语言重新总结。
