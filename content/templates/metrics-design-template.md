# AI 产品指标设计模板

## 模板用途

用于为 AI 产品建立使用、效果、成本、留存、质量和风险指标体系。

## 适用场景

AI 功能上线前、增长分析、模型评估、项目复盘和管理看板设计。

## 使用方法

先明确产品目标，再把指标拆成六类。每个指标必须有口径、数据来源和异常后的行动。

## 模板正文

```md
# AI 产品指标体系：{产品名称}

## 1. 产品目标
- 目标：
- 核心任务：

## 2. 指标表
| 类型 | 指标 | 口径 | 数据来源 | 异常动作 |
| --- | --- | --- | --- | --- |
| 使用 | | | | |
| 效果 | | | | |
| 成本 | | | | |
| 留存 | | | | |
| 质量 | | | | |
| 风险 | | | | |

## 3. 看板结构
- 总览：
- 功能分析：
- 成本分析：
- 风险告警：
```

## 填写示例

RAG 产品的无答案率口径可以定义为：系统明确拒答或未找到依据的问题数 / 总提问数。异常动作是补充知识、调整检索或优化 Prompt。

## 常见错误

- 只看调用量。
- 指标没有口径。
- 看板没有对应行动。
