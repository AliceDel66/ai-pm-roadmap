# AI 产品技术协作能力

本阶段让你从“画页面”走向“能和技术团队把 AI 功能做出来”。你会学习如何阅读 API 文档、理解流式输出、设计数据字段、评估模型成本，并把技术约束写入 PRD。

课程大纲：

1. API 与接口文档：请求参数、返回字段、鉴权和错误码。
2. 流式输出：为什么对话产品需要边生成边展示。
3. 模型接入：模型参数、模型路由、失败重试和降级。
4. 数据库与数据结构：会话、消息、知识库、用量和权限。
5. 日志、监控与成本：如何发现问题、控制预算。
6. 阶段项目：输出技术协作文档。
