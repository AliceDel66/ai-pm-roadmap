# Token

## 新手解释

Token 是模型处理文本的基本单位，可以粗略理解成文字被切成的小片段。

## 专业解释

模型输入输出会被分词器切分为 Token。模型调用成本、上下文长度和生成速度通常都与 Token 数量相关。

## AI 产品经理需要知道什么

长文档、历史对话、检索片段和输出长度都会增加 Token。产品经理要在效果和成本之间做取舍。

## 实际产品场景

对话历史是否全部保留、知识库检索片段取多少、报告生成限制多长。

## 常见误区

不要以为用户看见的字数就等于 Token 数。不同语言和格式切分方式不同。
