# Context Window

## 新手解释

上下文窗口可以理解为模型一次“能看见”的信息范围。用户输入、系统提示词、历史对话、检索片段和模型输出都会占用这个范围。

## 专业解释

Context Window 是模型单次推理可处理的最大 Token 数。超过窗口的内容无法完整参与生成，通常需要截断、摘要或检索。

## AI 产品经理需要知道什么

产品经理不需要精确计算分词，但必须知道上下文窗口影响长文档处理、多轮对话、成本和响应速度。窗口大不代表应该把所有内容都塞进去。

## 产品场景

- 聊天助手需要决定保留多少轮历史。
- RAG 产品需要只放入相关文档片段。
- 长文总结需要先分段或摘要。

## 常见误区

认为上下文越大越好。无关内容越多，成本越高，模型也可能更容易抓错重点。
